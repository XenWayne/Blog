众所周知你游窗口化不能缩放，对于高分屏十分不友好。  
这里介绍一个[补丁](https://hisouten.koumakan.jp/wiki/Misc_tools),在这里查阅SWRSToys模块，下载对应的则的版本，解压后放到则的目录里（保证d3d9.dll和th123.exe在同一个目录下）。  

参考目录结构:

```cmd
./
│  SWRSToys.ini
│  SWRSToys.txt
│  th123.exe
|  d3d9.dll
│  more...
├─Modules
│  ├─BGMChanger
│  ├─MemoryPatch
│  ├─NetBattleCounter
│  ├─NetBellChanger
│  ├─NetProfileView
│  ├─ReplayDnD
│  ├─ReplayInputView
│  └─WindowResizer
│          WindowResizer (simple engrish instructions).txt
│          WindowResizer.dll
│          WindowResizer.ini
│
└─more...
```

打开SWRSToys.ini，将含有WindowResizer的那一行开头的分号去掉，保存。  

SWRSToys.ini
```ini
[Module]
; MemoryPatch=Modules/MemoryPatch/MemoryPatch.dll
; NetBattleCounter=Modules/NetBattleCounter/NetBattleCounter.dll
; NetProfileView=Modules/NetProfileView/NetProfileView.dll
;  ReplayInputView=Modules/ReplayInputView/ReplayInputView.dll
  WindowResizer=Modules/WindowResizer/WindowResizer.dll
; BGMChanger=Modules/BGMChanger/BGMChanger.dll
; NetBellChanger=Modules/NetBellChanger/NetBellChanger.dll
; ReplayDnD=Modules/ReplayDnD/ReplayDnD.dll
```

打开Modules/WindowResizer/WindowResizer.ini，将`[Size]`和`[Position]`下的Enabled改为1，保存,两个配置分别对应窗口大小和窗口位置记忆。 

```ini
[Size]
Enabled=1

[Position]
Enabled=1
```

除此之外SWRSToys还有很多实用功能，可自行阅读文档。
